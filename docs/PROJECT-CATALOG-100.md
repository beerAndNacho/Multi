# Multi · 100개 프로젝트 후보 로드맵

기준일: 2026-08-17

## 방향

- 001은 현재 구현된 `오늘의 명리`.
- 002~100은 **검색 유입형 생활 도구 → 반복 사용형 업무 도구 → AI/B2B 도구 → 개발자 도구 → 바이럴 실험 → 통합 허브** 순으로 배치한다.
- 범용 AI 챗봇보다 하나의 명확한 문제를 빠르게 해결하는 도구를 우선한다.
- 법·세금·보험·지원금처럼 기준이 바뀌는 프로젝트는 화면에 `기준일`을 표시하고 공식 자료 기반 데이터만 사용한다.
- AI가 없어도 계산 가능한 기능은 로컬/결정적 로직으로 처리하고, AI는 설명·요약·문구 생성에만 사용한다.

## 개발 운영 원칙

### 프로젝트 1개당 완료 조건

1. 모바일 우선 UI
2. README에 목적·입력·출력·수익모델·향후 과제 기록
3. 최소 1개 핵심 기능은 로그인 없이 체험 가능
4. 개인정보는 기본적으로 브라우저에서 처리하고 서버 저장은 필요한 경우에만 도입
5. 계산기는 단위 테스트, AI 도구는 입력/출력 스키마 테스트 추가
6. OG 이미지·title·description·canonical 기본 제공
7. 운영비가 드는 AI 기능은 무료 호출 횟수 제한 또는 유료화 경계 설정
8. 정책/가격/규정 데이터는 기준일과 출처를 화면에 표시
