# Project 005 · 프리랜서 3.3% 계산기

기준일: 2026-08-18

## 1. 목표

광고 기반 검색 유입형 도구의 첫 번째 저비용 검증 프로젝트.

핵심 가설:

1. 사용자는 `3.3 계산기`, `프리랜서 3.3`, `3.3 역산`, `100만원 3.3 세후`처럼 즉답형 검색을 한다.
2. 계산 결과를 본 뒤 세금 신고·환급·계약서·프리랜서 비용 관리 같은 인접 콘텐츠로 이동할 수 있다.
3. 계산 자체는 브라우저에서 처리해 운영비를 0원에 가깝게 유지할 수 있다.

## 2. MVP 범위

- 세전 → 세후
- 세후 → 세전 역산
- 소득세 / 지방소득세 분리
- 월 건수 기반 월/연간 예상
- 결과 복사 / 공유
- 모바일 우선 반응형 UI
- SEO metadata / FAQ / 구조화 데이터
- AdSense 위치 2곳
- 서버 저장 없음

## 3. 수익화 순서

### Phase A · 트래픽 검증

- 무료 전체 기능
- Google Search Console 등록
- GA4 이벤트: calculate, reverse, share, copy
- AdSense 승인 후 본문 중간 + 결과 아래 광고 테스트

### Phase B · 검색 확장

롱테일 랜딩 추가:

- 30만원 3.3 계산
- 50만원 3.3 계산
- 100만원 3.3 계산
- 300만원 3.3 계산
- 3.3 역산 계산법
- 프리랜서 원천징수와 종합소득세 차이

### Phase C · 고단가 확장

트래픽이 확인되면 다음 기능을 같은 방문자에게 연결:

- 프리랜서 부가세 계산기
- 종합소득세 준비 체크리스트
- 견적서 / 인보이스 생성
- 계약금·중도금·잔금 계산
- 월 고정비 / 목표 매출 계산

## 4. 광고 배치 원칙

- 계산 입력 영역 내부에는 광고를 넣지 않는다.
- 첫 광고는 결과 확인 이후에 배치한다.
- 두 번째 광고는 정보성 본문과 FAQ 사이에 배치한다.
- 초기에는 광고 개수보다 페이지 속도와 검색 만족도를 우선한다.

## 5. 핵심 KPI

- Search Console 노출 / 클릭
- 계산 완료 횟수
- 역산 모드 사용률
- 공유/복사율
- 재방문율
- 페이지 RPM
- 광고 viewability

## 6. 필요한 외부 값

배포/수익화 시 사용자에게 받을 값:

- 운영할 도메인 또는 서브도메인
- AdSense Publisher ID (`ca-pub-...`)
- 광고 슬롯 ID 2개
- GA4 Measurement ID (선택)

위 값이 없어도 MVP 개발과 무료 배포 준비는 진행 가능하다.
