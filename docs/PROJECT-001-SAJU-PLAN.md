# Project 001 · 오늘의 명리 제품 기획 v1

## 1. 제품 목표

`오늘의 명리`는 사주를 어려운 명리 용어 나열이 아니라 **입력 → 계산 → 이해 → 비교 → 다시 시도**가 자연스러운 모바일 웹 서비스로 제공한다.

핵심 원칙은 다음과 같다.

1. 사주와 궁합이 **하나의 출생정보 모델과 계산 엔진**을 공유한다.
2. 사용자가 입력을 언제든 수정하고 다시 계산할 수 있어야 한다.
3. 출생시간을 모르는 경우 결과 정확도 차이를 UI에서 명확히 알린다.
4. 궁합 점수는 운명을 단정하는 값이 아니라 **일간·음양·오행 분포를 단순 비교한 참고용 밸런스 지수**로 설명한다.
5. 무료 계산과 향후 AI/결제 기능을 분리해, 무료 기능은 외부 키 없이도 항상 동작한다.

## 2. 정보 구조

상단 서비스 메뉴는 두 개로 유지한다.

- **내 사주**: 한 사람의 원국과 오행 밸런스
- **궁합**: 두 사람의 공통점·보완점·차이 비교

향후 확장 예정:

- 올해운 / 세운
- 대운
- 연애·결혼·직장/동료 관계별 상세 궁합
- AI 상세 해석
- 결과 공유 카드

## 3. 공통 출생정보 모델

사주와 궁합 A/B 모두 아래 필드를 동일하게 사용한다.

```ts
type BirthProfile = {
  name?: string;
  gender: 'male' | 'female';
  calendarType: 'solar' | 'lunar';
  birthDate: string;
  birthTime: string;
  timeKnown: boolean;
  leapMonth: boolean;
};
```

### 입력 규칙

- 성별: 필수
- 양력/음력: 필수
- 생년월일: 필수
- 출생시간: 기본 필수, `시간 모름` 체크 시 비활성화
- 윤달: 음력일 때만 노출/적용
- 시간 모름 시 시주는 결과에서 제외하고 `6글자 기준`임을 표시

## 4. 계산 엔진

공통 `calculateSaju(profile)` 함수가 아래 결과를 반환한다.

```ts
type SajuChart = {
  pillars: Pillar[];
  counts: Record<ElementKey, number>;
  strongest: ElementKey;
  weakest: ElementKey;
  dayMaster: string;
  dayMasterElement: ElementKey;
  dayMasterYinYang: '음' | '양' | '';
  zodiac: string;
  solarDate: string;
  lunarDate: string;
  totalChars: 6 | 8;
};
```

원국 계산은 `lunar-javascript`를 사용한다. 성별은 원국 자체를 변경하지 않지만 프로필 표시와 향후 대운/세운 확장을 위해 공통 모델에 포함한다.

## 5. 궁합 모델

### 입력

A와 B 각각:

- 이름/호칭(선택)
- 성별
- 양력/음력
- 생년월일
- 출생시간
- 시간 모름
- 윤달

추가 입력:

- 관계 유형: `연애`, `결혼`, `친구`, `직장/동료`

### 결과

궁합은 하나의 점수만 보여주지 않고 4개 축으로 분해한다.

1. **오행 조화**: 두 사람의 오행 분포 차이와 공통점
2. **상호 보완**: 한 사람의 약한 오행을 상대의 강한 오행이 보완하는 정도
3. **일간 관계**: 일간 오행의 생·극 관계를 참고 지표로 반영
4. **음양 리듬**: 일간의 음/양 조합을 참고 지표로 반영

최종 점수는 위 네 축의 가중 평균이며, 결과 화면에서 세부 점수를 함께 공개해 “왜 이 점수인지” 알 수 있게 한다.

### 점수 정책

- 90~100: 매우 높은 조화
- 80~89: 강한 조화
- 70~79: 편안한 조화
- 60~69: 차이를 조율하면 좋은 관계
- 59 이하: 차이가 큰 편, 소통 방식 확인 권장

점수는 재미·자기이해용이며 미래의 관계 결과를 예측하지 않는다.

## 6. UX 흐름

### 내 사주

1. 입력
2. 계산
3. 결과 표시
4. `입력 수정해서 다시 보기`
5. 수정 후 재계산
6. `이 정보를 궁합 A에 사용` 가능

결과가 떠도 입력 폼은 유지되며 모든 필드는 다시 활성화할 수 있어야 한다.

### 궁합

1. A/B 정보 입력
2. 관계 유형 선택
3. 궁합 계산
4. 종합 점수 + 4개 세부 점수
5. 잘 맞는 점 / 주의할 점 / 관계 유형별 팁
6. A/B 입력 수정 후 즉시 재계산

## 7. 모바일 UX

- 480px 이하에서는 모든 입력을 1열로 표시
- 결과 카드도 1열 우선
- 상단 `내 사주 / 궁합` 이동 버튼은 sticky
- 날짜/시간 필드는 결과 후에도 수정 가능
- 비활성화된 시간 필드는 체크 해제 즉시 다시 활성화
- 오류는 해당 폼 내부에 표시

## 8. 공유/SEO

- `og:title`, `og:description`, `og:image`, `twitter:card` 제공
- OG 이미지는 PNG 사용
- 공유 문구는 사주/궁합 모두 포괄하는 제목으로 유지
- 향후 개인 결과를 URL에 직접 담지 않아 생년월일 개인정보가 공유 주소에 노출되지 않도록 한다.

## 9. 품질 기준

출시 전 최소 체크리스트:

- 양력 계산
- 음력 계산
- 음력 윤달
- 시간 모름 → 시간 다시 켜기
- 결과 후 날짜/시간 재선택
- A/B 성별 입력
- A/B 시간 모름 재선택
- 관계 유형 변경 후 재계산
- 모바일 360px 레이아웃
- 잘못된 날짜 오류 처리
- 동일 인물 A/B 입력 시 오류 없이 결과 표시
- 공유 OG 메타 및 PNG 경로 확인
