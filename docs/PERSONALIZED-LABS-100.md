# Personalized LAB 100 Catalog

현재 상황을 빠르게 정리하고 다음 행동을 제안하는 개인화 생활 도구 100개입니다.

- 통합 허브: `https://beerandnacho.github.io/labs/`
- LAB-01: `https://beerandnacho.github.io/date-course/`
- LAB-02: `https://beerandnacho.github.io/after-work/`
- LAB-03~100: `https://beerandnacho.github.io/labs/<slug>/`
- 전체 기계 판독 색인: `apps/personalized-labs/labs-index.js`
- 선택값과 최근 사용 기록은 현재 브라우저의 `localStorage`에만 저장됩니다.

## 공통 품질 기준

- 모든 LAB에 개인화 질문 4개 이상, 결과 4개 이상
- 추천 이유, 실행 3단계, 대안 결과, 저장·공유
- clean URL, 최근 사용, GA4·Microsoft Clarity 훅
- 25가지 구조적 레이아웃을 순환하되 LAB별 데이터·색·문서 은유를 분리
- GitHub Actions에서 100개 색인, LAB-03~100 총 98개 런타임, 질문·결과·레이아웃·CSS 누락을 검사
